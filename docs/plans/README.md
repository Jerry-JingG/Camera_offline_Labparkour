## 设计文档与架构文档的区别

### 架构文档（Architecture）
- 关注"是什么"（What）
- 描述系统的高层结构
- 定义组件和接口
- 长期稳定，不常变化

### 设计文档（Plans）
- 关注"怎么做"（How）
- 描述具体实施方案
- 包含详细技术细节
- 随项目进展更新

## 使用建议

### 何时阅读设计文档

- 开始具体实施前
- 需要了解实施细节时
- 评估工作量和时间时
- 制定开发计划时
- 进行技术评审时

### 阅读顺序

1. **先读架构文档**
   - 理解整体设计
   - 了解系统组件

2. **再读设计文档**
   - 了解实施方案
   - 掌握技术细节

3. **参考阶段文档**
   - 查看实际实施情况
   - 学习经验教训
